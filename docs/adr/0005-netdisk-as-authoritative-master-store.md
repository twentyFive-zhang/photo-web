# 网盘为母版唯一权威存储，发布库只存展示变体（修订 ADR 0002）

取代 ADR 0002 中「发布库（本地存储，M6 后为 COS）是照片原件的唯一权威存储、网盘只是热备份镜像」的结论；其「网盘不做运行时图床」（源自 ADR 0001）继续有效。

## 决策

**百度网盘（源文件库）= 照片母版唯一权威存储；本地发布库只存展示变体 thumb(400) + display(1600)**。2560px 的 large 档整体移除（新的两档足够覆盖缩略图与灯箱展示，省一档存储与生成成本）。

- **本地上传 → 首推成功即删**：上传生成两档变体落本地，原件临时落本地（staging）→ 异步推送百度网盘 → 推送成功后删除本地原件（仅原件，变体保留）。推送失败自动重试，成功前原件一直在本地——任何时刻照片都有母本，无「无母本」真空期。原件删除 best-effort，失败只记日志不让推送报错（网盘上已有权威副本，残留可再清理）。
- **访客服务 = 本地变体（S1）**：展示全程走本地 thumb/display，百度不在访客路径上。官方图床禁令否决了一切「访客流量走网盘」的方案（含 S3 纯代理方案），用户知情后改选本方案。
- **网盘导入更纯粹**：原件本就在网盘——导入拉一次 buffer（sha256 / EXIF / 变体）后不落本地原件、不入 staging、不触发推送，直接回写 fsId 映射。
- **容灾反转**：
  - 新增「从网盘重建变体」（admin 动作，单张起步）：dlink 下载原件 → sha256 校验 → sharp 重生成 thumb+display（复用导入管线下载段）。本地变体丢失/损坏时用。
  - 原「缺失/重推」链退役改造：每日扫描已镜像但网盘消失的照片 → 语义变为**母本丢失告警**（本地无原件，不可自动修复），设置页呈现为醒目告警而非可修复项，「重推缺失」按钮移除；推送失败列表的重推**保留**（staging 原件还在，可修复）。
- **存量迁移**：现网 2 张照片均已镜像——验证 dlink 可下载（sha256 一致）后删本地原件 + large.webp + PhotoRendition large 行（DB 行走 prisma 迁移，文件清理走一次性命令，见 PR 描述）。

## 官方约束事实（决策依据）

来源：百度网盘开放平台文档（pan.baidu.com/union/doc，平台简介/使用规范）。

- **图床禁令**：开放平台使用规范原文「利用个人网盘账号进行企业建站、图床、搭建网盘迁移工具等」+ 封禁/追责条款。访客流量走网盘（直链/代理/分享）全部排除。
- **配额**：未过上线审核 10 次/小时/接口、10 用户上限。个人备份语义不踩图床禁令，但量级上去需走应用上线审核。
- **token**：access_token 30 天；**refresh_token 一次性**——每次刷新必须把新 refresh_token 落库。本单已审查现有 `BaiduCredentialService.doRefresh()`：刷新成功即经 `save()` 把新 access_token/refresh_token 一并加密落库（apps/api/src/baidu/baidu-credential.service.ts），无需改动。
- **dlink**：8h 过期、UA 防盗链（固定 `pan.baidu.com`）、>50MB 禁浏览器下载——只可服务端使用，绝不持久化。
- **上传**：4MB 固定分片、≤4GB、≤1024 分片、无格式限制；precreate 带 content-md5+slice-md5 时 return_type=2 即秒传（重推场景可选优化）。

## 理由

- 母版已经天然存在于网盘（导入）或会被推上网盘（上传）。让本地长期冗余一份原件只换来「多一份备份」，却要持续付出存储成本；而真正的展示路径只消费两档变体。
- 原件删除后，本地丢失的只是「可再生的变体原料」的本地副本，母本仍可随时经 dlink 拉回（8h 时效对服务端拉取无影响）。
- 「无母本真空期」被 staging 语义消除：推送成功前原件一直在本地，推送成功即有网盘权威副本，两个状态无缝衔接。

## 代价

- 母本单点在网盘：网盘侧被删且超出回收站期，照片母版即永久丢失。缓解：每日扫描的母本丢失告警（尽早发现）+ 站内删除不碰网盘（文件自动转托管归档，见下方 2026-11-22 注记）。
- 重建变体依赖网盘可用性与限流（10 次/小时/接口未过审时批量重建受限）；单张起步，批量后续再评估。
- 推送失败的照片会暂时占用双份原件存储（本地 staging + 无网盘副本），以推送成功为界自动收敛。
- PG 不支持 DROP VALUE，PhotoVariant 枚举经类型重建迁移收窄为 THUMB/DISPLAY。

2026-11-22 经 grilling 决策会确定全部分支（用户多轮拍板）；实现随本 ADR 同步落地。

> **2026-11-22 注记（JIANGLIUER-102）**：站内删除语义自此调整——删除（专辑/单张/批量）不碰网盘，被删照片的网盘文件自动转**托管归档**（fsId/path 登记进 `SiteSetting.netdiskManagedFiles`，下行扫描跳过）；恢复 = 在设置页解除托管，下轮扫描按目录重导（专辑以 UNLISTED 形态按目录名重建）。原「站内删除 → 待确认删除 → 人工确认删网盘」流程同步退役（ADR 0002 删除语义以本注记为准）。
