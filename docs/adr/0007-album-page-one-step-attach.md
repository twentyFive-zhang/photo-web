# 专辑页一步挂专辑：添加照片弹窗三来源合一（修订 ADR 0006 的两段式 UX）

修订 ADR 0006「收编两段式」的 UX 层：**库为唯一照片入口的内核不变**——照片仍只能经导入或本地上传产生；改变的是专辑页不再让管理员手动走两步。ADR 0006 自己列出的代价「新照片入库需要导入 + 挑图两步」，在高频路径（给专辑配图）上由本决定焊成一步。

## 决策

- **专辑页「添加照片」为一个弹窗、三个来源 tab**：照片库挑选 / 本机上传 / 网盘选。三个来源的终态一致：照片存在 + 纳入当前专辑。
- **「从网盘导入」独立按钮取消**：专辑页的网盘选择复用网盘管理页的文件树组件（只取浏览 + 勾选；仅文件多选，文件夹仅作导航），提交走现有导入管线并附带目标专辑 id，导入成功后自动纳入。
- **本机上传走现有上传管线**（原件异步推送源文件库），上传成功后即纳入当前专辑；支持一次多选，失败行内重试。
- **网盘导入保持异步**：提交即关弹窗并提示导入中，导入完成自动纳入，不做占位卡片（第一版）。
- **「同步到网盘」专辑按钮与对应端点删除**：本地上传路径本已自动推送；推送失败件由设置页推送失败卡片兜底（重推 / 忽略）。push 队列与 worker 保留（上传链路复用）。

## 理由

- 两段式内核（导入只产生照片、纳入独立成词）毫发无损，只是给专辑页提供「导入 + 纳入」的复合动作；零新增存储逻辑。
- 树形组件复用而非重写，网盘管理页行为不变。

## 代价

- 导入管线新增可选专辑参数，导入成功回调多一次成员写入；专辑失效时该次纳入静默降级为仅入库。
- 添加照片弹窗从单一选择器变为三 tab 复合组件。
